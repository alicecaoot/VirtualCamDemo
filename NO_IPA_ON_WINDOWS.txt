========================================================
为什么这里没有「能直接装上 iPhone 运行」的 IPA 二进制？
========================================================

当前电脑是 Windows，没有：
  - Xcode / iOS SDK
  - clang 的 apple arm64-apple-ios 目标工具链
  - Theos

IPA 里的主程序必须是 arm64 Mach-O。Windows 上无法凭空生成可执行的 iOS 二进制。
若有人直接给你一个在 Windows 上「打包」的 IPA 却声称能跑，那通常是空壳或无效包。

请你：
  1. 把整个 MyFirstTweak 文件夹拷到 Mac
  2. 安装 Xcode + Theos
  3. 执行：
       export THEOS=/opt/theos
       cd MyFirstTweak
       chmod +x build_ipa.sh
       ./build_ipa.sh
  4. 得到 dist/VirtualCamDemo.ipa 后用 TrollStore / AltStore 等安装

Android 的 VCAM_GUARD_LD14_FIXED.apk 不能转成此 IPA。
